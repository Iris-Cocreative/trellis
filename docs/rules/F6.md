# F6 · Scroll is a timeline

**Withdrawn** by D71: moved out of the rules into the plan for `.scene` and Motion proportions until something uses it. The page and its ID stay; it returns as a rule with the first scene.

## Statement

Scroll scenes use CSS scroll-driven animation (`animation-timeline: view()`), not scroll listeners.

## Why

A scroll listener runs on the main thread and lags behind the scroll. A scroll timeline runs with it.

## The failure it prevents

A scene that stutters behind the reader's finger on a phone.

## How it is checked

Not checked.

## Example

None in the code yet.

## Exceptions

Script that follows an anchor (a float) or redraws the specimen's grid listens to scroll; neither is a scroll scene.

## Why it was withdrawn

Nothing in Trellis used scroll-driven animation yet: `core.css`, the specimen and the experiments have no `animation-timeline`. The `.scene` that would use it is named in the README and not built. The rule is a promise with no example and no test.
