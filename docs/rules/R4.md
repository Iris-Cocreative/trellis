# R4 · Draw grids in device pixels

## Statement

Draw grids in device pixels, never with repeating CSS gradients.

## Why

Safari rounds each repeated gradient tile separately, so the error grows across the screen. A canvas at device resolution draws each line on the pixel its coordinate rounds to, the same way WebKit places a box's edge.

## The failure it prevents

A grid whose lines drift away from the box edges they should coincide with, worse toward the right and bottom of the screen.

## How it is checked

`tests/pixel.js` checks card edges against the grid canvas's pixels in WebKit at 3×. That would fail if the grid were drawn by gradient tiles. The ban itself is review only: no test looks for a repeating gradient.

## Example

The specimen's grid is a `canvas` sized to the device's pixels, redrawn when the cell or the screen changes.

## Exceptions

None.
