# R13 · One concept, one primitive

## Statement

One concept, one primitive. Variants are `cc-*` modifiers that change the primitive's own variables.

## Why

The drift this foundation was built against was many separate builds of the same avatar, modal and pill. One archetype per concept means a fix or a product's change lands everywhere at once.

## The failure it prevents

A second button class that looks almost the same as the first, and drifts.

## How it is checked

Review only for the rule. `tests/contract.js` fails if any class in `core.css` is missing from the README's Public API, so a new class can't arrive unannounced.

## Example

`.tag.cc-lg` sets `--tag-h` and `--tag-fs`; it does not restate the tag's padding, border or radius.

## Exceptions

None.
