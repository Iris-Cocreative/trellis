# R7 · Center only what differs by an even number of cells

## Statement

Center a thing inside another only when their sizes differ by an even number of cells; otherwise align it to `start`.

## Why

Centering splits the difference in two. An even difference splits into whole cells on each side, so both edges land on lines (R1). An odd difference leaves half a cell on each side.

## The failure it prevents

A centered box whose edges sit half a cell off the lattice.

## How it is checked

Review only. `tests/align.js` would catch the result as a box off its line, but nothing checks the rule itself.

## Example

A 4-cell icon in an 8-cell tile centers: 2 cells each side. In a 7-cell tile it aligns to start.

## Exceptions

A box centered on a line rather than inside a box follows R1: it is even, and overhangs the line equally.
