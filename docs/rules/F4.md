# F4 · Spans, not pixels

## Statement

A creative arrangement is written in cells or modules and re-placed by container queries.

## Why

Pixels are true at one width only. Spans in cells stay true as the cell and the container change.

## The failure it prevents

An asymmetric layout that is right at 1440px and broken at every other width.

## How it is checked

Review only.

## Example

A feature tile spans 8 cells by 6 in a wide container and the full width by 6 in a narrow one, through `--cell-w` set in a container query.

## Exceptions

None.
