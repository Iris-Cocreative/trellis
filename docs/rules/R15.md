# R15 · Context changes variables, not markup

## Statement

Context changes variables, not markup: `.cc-dense .card { --card-pad: u }`. A card is a container, so its type scales to it.

## Why

A component that needs different markup per context can't nest. A component that only reads variables can sit at any depth and take its context from above.

## The failure it prevents

A "compact card" component that duplicates the card's markup for one sidebar.

## How it is checked

Review only.

## Example

The same `.card` markup in a page section and in a `.cc-dense` sidebar: padding, tags and buttons get smaller there, and the markup is identical.

## Exceptions

None.
