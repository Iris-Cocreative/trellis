# R12 · Overhangs are given back

## Statement

An icon taller than the line beside it takes negative margin for its whole height below its offset, so the line keeps its own height.

## Why

A line's height comes from its text. Anything taller in it would stretch the line, as a mark would (R10), and move what follows off its count.

## The failure it prevents

A list row or a label that grows by a few pixels because the icon in it is larger than its line.

## How it is checked

Review only.

## Example

A 2-cell icon beside a 1-cell line of text: it is centered on the text, and gives back the cell it overhangs.

## Exceptions

None stated.

## Questioned

The code does not keep this as a mechanism. `core.css` has no rule that gives an icon's overhang back; `.icon` sets only its size and stroke. Each component that puts a large icon beside text has to do it by hand, and no test would notice one that didn't.
