# R11 · Truncate sideways only

## Statement

Truncate sideways only, with `.u-truncate`: `overflow-x: clip`, with the block direction left visible.

## Why

Text boxes are trimmed to the capitals and the baseline. A trimmed box ends at the baseline, so `overflow: hidden` on it cuts off every descender.

## The failure it prevents

Truncated labels whose g, p and y lose their tails.

## How it is checked

Review only. The tag label uses the same declaration since tags got a maximum width; no test looks for `overflow: hidden` on trimmed text.

## Example

A long tag label in a narrow row ends in an ellipsis, with its descenders intact.

## Exceptions

None.
