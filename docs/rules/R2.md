# R2 · Columns round to cells

## Statement

`.cols` rounds every track down to whole cells, so each column's left edge is on a line. `.grid` uses fixed tracks that don't stretch. `.split` rounds its first column the same way.

## Why

A column that is a fraction of its container would start between lines, and so would everything in it.

## The failure it prevents

Text and cards in the second or third column sitting off the cells while the first column is on them.

## How it is checked

`tests/align.js` measures the left edge of every box, including each column and what it holds. In `core.css` the tracks are `round(down, …, var(--u))`.

## Example

Three columns in a 40-cell field with a two-cell gap: each track is 12 cells, and the cell left over sits at the end.

## Exceptions

None. A layout that needs fractional columns is not a `.cols`.
