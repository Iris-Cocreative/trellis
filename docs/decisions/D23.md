# D23. Settle everything in one pass

## Context

A page with thousands of rows is expensive to settle the first time.

## Options considered

Settle lazily behind an IntersectionObserver: impossible, because a visible block's position is the sum of every block above it. Slice the work across frames: adaptive slices took 2,600 to 2,900ms, fixed slices of 2,048 took 1,830 to 1,960ms, all at once took 790 to 840ms, with the same longest frame each time. All at once: chosen.

## Decision

`settle.js` settles everything queued in one pass, in one frame.

## Consequences

The first settle is the expensive one. Rendering fewer rows (virtualizing) helps more than any policy here, and a virtualized row is whole cells. `tests/perf.js` holds the budgets.
