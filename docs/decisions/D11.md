# D11. Draw grids in device pixels

## Context

The specimen draws the grid so a reader can see edges land on lines.

## Options considered

Repeating CSS gradients: rejected, because Safari rounds each repeated tile and the error grows across the screen. A canvas at device resolution: chosen.

## Decision

Grids are drawn in device pixels on a canvas, never with repeating CSS gradients.

## Consequences

Rule R4. The canvas uses the same rounding as WebKit, so a card's edge and its grid line are the same physical pixel.
