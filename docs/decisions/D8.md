# D8. Round the fitted cell to 1/32px

## Context

A fitted cell is fractional. Browsers lay out on a 1/64px grid.

## Options considered

Not recorded. The sources say what was chosen, not what else was weighed. Flagged for the owner.

## Decision

The fitted cell rounds down to 1/32px, so every half cell is exact in the browser's 1/64px layout grid and nothing drifts.

## Consequences

The cells fall short of the screen by up to about a pixel, split between the edges. `math.js` rounds the same way.
