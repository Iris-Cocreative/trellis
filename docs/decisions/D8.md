# D8. Round the fitted cell to 1/32px

## Context

A fitted cell is fractional. Browsers lay out on a 1/64px grid.

## Options considered

Not weighed at the time. Options named since, though the arithmetic limits the field: no rounding, which leaves an error below 1/64px to add up down a page; 1/64px, which makes a half cell inexact; a whole device pixel, which cannot span a screen with whole cells and leaves up to a third of a pixel per cell.

## Decision

The fitted cell rounds down to 1/32px, so every half cell is exact in the browser's 1/64px layout grid and nothing drifts.

## Consequences

The cells fall short of the screen by up to about a pixel, split between the edges. `math.js` rounds the same way.

## Date

2026-10-28. The rounding first appears in the 0.3.0 commit; the changelog does not name it.

## Who

Not recorded. It shipped in 0.3.0.
