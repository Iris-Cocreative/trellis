# D27. Motion uses the grid's proportions

## Context

The free-layout rule said motion is transform and opacity only (D20). That ruled out motion that moves layout on purpose.

## Options considered

Keep the rule, or withdraw it. Withdrawn.

## Decision

Motion uses the same proportions as the grid and the ratio. It is not limited to transform and opacity. It may use the system or break from it on purpose. Every motion still starts and ends at a rest position on the lattice.

## Consequences

Rule F1 now says only that rest positions are on the lattice. What motion may use is still to be written (Motion proportions). The README and the specimen dropped the old sentence in 0.9.0.
