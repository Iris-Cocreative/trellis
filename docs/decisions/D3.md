# D3. Type answers to its container

## Context

A component appears in a page, a sidebar and a card. Type sized from the window reads wrong in all but one of them.

## Options considered

The Type Scale Generator this scale came from computes its clamp against the viewport. Container units were chosen over that, for the reason above.

Not weighed at the time. Options named since: sizes stepped at breakpoints; fixed sizes with a density context.

## Decision

Type sizes come from the container (`100cqi`), using the fluid, fractal scale from the Type Scale Generator: two anchors, each a straight line between a narrow and a wide space.

## Consequences

A role inside a card scales to the card. A context changes variables, never markup (R15). Known wrinkle: xs is larger in a narrow space than a wide one, so CSS holds it fixed (open question 1).
