# D53. Scripts read the cell from a probe

## Context

WebKit computes the registered `--u-px` against the default 16px when a page or app sets the root font size, which is how an iOS web view usually scales text. `settle.js` read `--u-px`, so in Safari it rounded every block with the wrong cell. `--u` itself is right in every engine.

## Options considered

Measure one hidden box sized by `--u`, or also define `--u-px` on `body` and read it there, which moves a public token. The probe was chosen.

## Decision

`settle.js` measures the cell from one hidden box on `<html>` (`[data-trellis-cell]`), and `Trellis.cell()` returns it for any script. `--u-px` stays as a convenience.

## Consequences

The specimen and the tests read the cell with `Trellis.cell()`. At 312% text WebKit reports the cell Chromium does.

2026-11-12

## Who

The owner.

## Superseded by

None. It supersedes the part of D6 that had scripts read `--u-px`.
