# D62. The tab bar pads like main

## Context

In the shell's narrow state the navigation becomes a tab bar. It padded half a cell on each side while main pads two cells, so the current link's fill ended half a cell from the shell's edge and lined up with nothing above it. The specimen's frame was also painted over by the sticky bar; that was a specimen fix.

## Options considered

Weighed at the time, on a decision card in the plan: A, the bar pads `--shell-pad` on either side, so the outer links' fills share main's content edge; B, links with no fill and a pill behind the current link's icon only, dividing the full width (a new `--shell-mark`); C, the current link shown by ink and a mark line on the bar's top edge.

## Decision

A. In the tab bar state `.shell-nav` pads `--shell-pad` on its sides, the same as main, so the first and last links' fills line up with main's content.

## Consequences

A visual change in the narrow shell only; no new variable. The active fill no longer meets the shell's rounded bottom corners. Navigation templates, where a tab bar template grows, moves to underway; B stays a candidate for it.
