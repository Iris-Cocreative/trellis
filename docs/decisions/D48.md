# D48. Native or web, per surface

## Context

In a hybrid app (D35), each new feature could reopen whether it is native or a web view.

## Options considered

Decide per feature as each comes up, or agree a default. The proposed default was agreed.

## Decision

Native for the shell, navigation, messaging and any long list. A web view for content, media, canvases and whatever the web app already does well.

## Consequences

The default is to be written where builders find it (Write down the surface default).

## Date

2026-11-11

## Who

The owner. The choice was for the owner and the builder of the mobile app together; only the owner's agreement is recorded.
