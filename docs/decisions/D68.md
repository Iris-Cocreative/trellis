# D68. Withdraw R12, overhangs are given back

## Context

R12 said an icon taller than the line beside it takes negative margin for its whole height below its offset, so the line keeps its height. Core had no mechanism for it (`.icon` sets only its size and stroke) and no test checked it, so each component did it by hand or not at all.

## Options considered

Weighed at the time, on a decision card in the plan: A, core gives overhangs back: `.icon`, or anything marked as overhanging, takes the negative margin itself, with a test; B, keep it as a review rule with no mechanism, and say so; C, withdraw it.

## Decision

C. R12 is withdrawn. Its page stays, marked withdrawn, and the README keeps the number 12 and says so. Whether an icon overhangs its line, and gives the overhang back, is the component's choice; R9 still says where it centers.

## Consequences

No code changes. A component that wants a large icon beside a line of text still gives the overhang back itself, as the specimen's checks list does. The Icons section shows an overhang as the component's choice.
