# D93. Type from seven values

## Context

Core sized type from twelve numbers and a product set every one: the two spaces, H1, body and the label at each end, the heading ratio at each end and the paragraph ratio at each end. Nothing tied one to another. In core's own defaults H1 sat 4.41 steps above body in a wide space and 4.45 in a narrow one, the label shrank, and the paragraph step was a number of its own.

The specimen's ratio playground set type from seven and worked the other five out. The two models were then set side by side on the specimen: every knob, which the playground set and which it derived, and every role's size in each. At core's defaults five of the twelve differed.

## Options considered

Weighed at the time, on that comparison:

Core keeps twelve free numbers, and the playground stays one way to fill them. Richer, and a product has to keep five numbers in step with seven by hand.

Core takes the seven and works the five out, each still settable. The shape color took in D90.

## Decision

Seven values set type: H1, body and the label in a wide space (`--h1-max`, `--body-max`, `--label-max`), the ratio in a wide space and in a narrow one (`--rh-max`, `--rh-min`), and the two spaces (`--c-min`, `--c-max`). The two spaces are product knobs now.

Five follow, and a product may set any of them in its place:

- **The text step** is the square root of the ratio, at each end (`--rp-max`, `--rp-min`). Two text steps make one heading step.
- **Body in a narrow space** is body less a narrow text step (`--body-min`).
- **H1 in a narrow space** sits as many steps above body as it does in a wide one (`--h1-min`).
- **The label** is one size (`--label-min`).

`core.css` states them with `sqrt()`, `pow()` and `log()`; `math.js` has them as `typeFrom()`.

## Consequences

- Breaking: `tokens.json` loses `h1-narrow`, `body-narrow`, `label-narrow` and the two `paragraph-ratio` tokens; `math.js`'s `SEED` gains `seven`, and `SEED.type` is worked out from it.
- A product layer that sets all twelve keeps them. One that sets only some of the five gets the rest from its own seven, where it had core's.
- A script cannot read a derived knob as a number: `--h1-min` is an expression until a size uses it. The specimen and the tests read the seven and let `math.js` work out the rest.
- The comparison on the specimen has done its work and is gone. The playground writes a product layer of the seven.
- `tests/math.js` measures every role in the browser against `typeFrom()`, in both engines, so it checks the three functions too.
