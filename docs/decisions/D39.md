# D39. Public is not a release

## Context

The repository is public from its first commit.

## Options considered

Two other options were weighed: stay private until both apps run on it, which was the decision of 2026-11-07; or publish to npm at once. Public now, release later, was chosen. The specimen and stylesheets were already served publicly, a private dependency costs every consumer a token, and CI and the site are free on a public repository.

## Decision

Version 1.0, npm, an announcement and open contributions wait until two apps run on the same version. Until then the README says pre-1.0, not taking contributions, and the package is private.

## Consequences

Semver stays 0.x, and a 0.x minor may break if the changelog says so. Install is by git address, pinned to a commit.
