# D39. Public is not a release

## Context

The repository is public from its first commit.

## Options considered

Not recorded. The sources say what was chosen, not what else was weighed. Flagged for the owner.

## Decision

Version 1.0, npm, an announcement and open contributions wait until two apps run on the same version. Until then the README says pre-1.0, not taking contributions, and the package is private.

## Consequences

Semver stays 0.x, and a 0.x minor may break if the changelog says so. Install is by git address, pinned to a commit.

2026-11-11

The owner.
