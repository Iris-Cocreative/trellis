# D44. The math as a module

## Context

The specimen computed the fit, the ratio and the rhythm inside its own script. A native screen needs the same arithmetic.

## Options considered

Not recorded. The sources say what was chosen, not what else was weighed. Flagged for the owner.

## Decision

`math.js` holds the fit, the ratio, standing, hanging and the gutter parity rule as plain functions in points, with no DOM. The README states the same formulas in words.

## Consequences

`tests/math.js` checks it against the stylesheet in both engines. It is a package export and takes its seed from `tokens.json`.
