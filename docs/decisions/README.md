# Decisions

Every choice behind Trellis, as a decision record, oldest first. Each page has the same shape: Context, Options considered, Decision, Consequences, Date, Who, Superseded by. See [the knowledge base](../README.md) for the conventions.

Records from 0.2.0 to 0.7.0 are written from the changelog, the README and the tests' notes, after the fact. Where those sources say what was chosen but not what else was weighed, the record says "Not recorded" and is flagged, so the owner can fill it in. Records dated 10 November are dated by the plan that holds them; the day each was made may be earlier.

A new choice gets the next number. A decision is not done until it is applied: the work it needs is its own item.
