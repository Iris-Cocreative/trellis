# Decisions

Every choice behind Trellis, as a decision record, oldest first. Each page has the same shape: Context, Options considered, Decision, Consequences, Date, Who, Superseded by. See [the knowledge base](../README.md) for the conventions.

Records from 0.2.0 to 0.7.0 are written from the changelog, the README and the tests' notes, after the fact. Where those sources said what was chosen but not what else was weighed, the owner has since filled in the options. Every record keeps two kinds apart: options weighed at the time, and options named since, marked "not weighed at the time". No record is flagged. Records first dated by the plan of 10 November now carry the day each was made, so a few dates run earlier than their number.

A new choice gets the next number. A decision is not done until it is applied: the work it needs is its own item.
