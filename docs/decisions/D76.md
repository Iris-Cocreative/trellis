# D76. Specimen before product, as a principle

## Context

"Nothing ships in a product before it is in the specimen" was a candidate principle, dropped because no rule or check kept it: `tests/contract.js` compares the README's Public API with `core.css`, not with the specimen.

## Options considered

Weighed at the time, on a decision card in the plan: A, make it a rule (R21) with a check that every Public API class appears in `index.html`; B, keep it as a principle with no check, and say so; C, leave it dropped.

## Decision

B. It is principle P7 on the principles page, kept by review, with no check, and the page says so.

## Consequences

The principles page lists one principle no rule or check keeps, and says why it is there anyway. Option A remains a small build if the specimen and the API drift.
