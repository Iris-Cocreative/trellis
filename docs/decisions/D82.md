# D82. Interaction presets: CSS where it can, one optional file

## Context

Seven interaction presets were approved as plans (D33): a glow under the finger on a scrollable field, scrollbars that appear on touch, scroll-edge fades, press states, sheet detents, swipe actions on rows and shared-element transitions. Each was to be named, tokenized, opt-in and safe under reduced motion. Press states were built as the state layer. `settle.js` was the one runtime file, and its job is settling layout; four of the presets are gestures.

## Options considered

Weighed at the time, on a decision card in the plan:

1. Where the script lives: A, CSS where CSS can and one optional second file, `presets.js`, for the rest ("one required runtime file"); B, everything in `settle.js`, each preset off until asked; C, CSS presets only, the rest as recipes an app writes.
2. How an element asks: A, a data attribute per preset; B, a class per preset.
3. Order: A, two waves, CSS first; B, all seven at once.

## Decision

1A, 2A, 3B. Fade and press are CSS in `core.css`. Glow, reveal, detents, swipe and share are in `presets.js`, which a page loads after `settle.js` if it wants them; `settle.js` stays the only file a page needs, and adds itself to a `window.Trellis` that `presets.js` may have made first. Each asks with `data-trellis-<name>`; each reads its knobs from `core.css` (`--fade-size`, `--press-scale`, `--glow-size`, `--glow-color`).

- Fade is a mask whose two stops a scroll-driven animation opens over the first and last `--fade-size` of the scroll, so a box that doesn't scroll, or a browser without the animation, draws no fade.
- Press sinks at once by `--press-scale` and returns the same way, so it replaces no transition a control already has.
- Glow is the field's background image, so the content never moves.
- Detents move the tray by a translate, not its height, keeping D20: the tray is as tall as its tallest detent. A tray with detents clips rather than scrolls, or focusing its close button would scroll it back up past the detent.
- Swipe moves the row's children by `--swipe-x`; the actions wait past the row's end, clipped.
- Share names elements for a view transition and wraps the change in `Trellis.transition`; cross-page transitions stay the app's to turn on.

## Consequences

- Additive. `presets.js` is a package export; the contract checks that it ships.
- Under reduced motion: durations collapse, press does not sink, view transitions stand down; glow, reveal, detents and swipe still work, without travel.
- A field with the glow sets its color with `background-color`: the `background` shorthand would clear the glow.
- `tests/layout.js` drives each preset with synthetic pointer events in both engines, wide and touch.
