# D6. Leave the cell and the count unregistered

## Context

A registered custom property is typed and animatable, which made `--u` and `--cells` look like they should be registered.

## Options considered

Registered: Chrome passed a registered length on at six significant digits (10.03125px became 10.0312px) and the page drifted; WebKit computed a registered cell count as 0, which left every iPhone blank in 0.3.0. Unregistered: they stay expressions and resolve the same on every element. Unregistered was chosen.

## Decision

`--u` and `--cells` are not registered. `--u-px` is a registered copy for scripts.

## Consequences

Layout is never built from `--u-px`. The same pattern holds for every value the fit computes.

## Date

2026-10-28

## Who

Not recorded. It shipped in 0.3.0 and 0.3.1.

## Superseded by

In part: D53 changes how scripts read the cell. `--u-px` stays as a convenience.
