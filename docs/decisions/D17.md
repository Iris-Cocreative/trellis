# D17. Five levels of layout

## Context

Layout needed a small vocabulary, so a unique design changes variables instead of inventing parts.

## Options considered

Not recorded. The sources say what was chosen, not what else was weighed. Flagged for the owner.

## Decision

Five levels, each with a few named parts: Page (`.frame`), Section (`.section`), Composition (`.stack`, `.cluster`, `.cols`, `.split`, `.grid`, `.cells`, `.rail`), Surface (`.card`), Element.

## Consequences

Later layouts (`.list`, `.shell`, `.cover`, `.board`, `.prose`) were added inside the levels, not as a sixth. The Anatomy chapter is built on this.
