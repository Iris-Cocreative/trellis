# D16. Control type is fixed and listed

## Context

Controls sit in rows of a fixed height.

## Options considered

The review session found raw font sizes inside primitives and offered two fixes: make them tokens, or write the rule that control type is fixed. Both were done.

Not weighed at the time. Option named since: control labels take the fluid type roles and scale with their container.

## Decision

Control labels do not scale with the container. `--fs-control-xs` to `--fs-control-lg` are the only font sizes outside the type roles.

## Consequences

Rule R17. Above the cell's cap a label can outgrow its control; D52 answers that.

## Date

2026-11-02

## Who

The build session, in answer to a point the review session raised. It shipped in 0.5.0.

None. D52 adds to it.
