# D26. Half-cell gaps reach clusters only

## Context

Rule R6 says space between blocks is whole cells, but `.u-gap-q` and `.u-gap-h` also set the stack's gap. Three rules disagreed.

## Options considered

Let half-cell utilities reach stacks, which puts everything after them off the grid, or keep them to clusters. Clusters only: chosen.

## Decision

`.u-gap-q` and `.u-gap-h` no longer set `--stack-gap`. A row that holds half-cell padding is one thing, its edges on lines and its contents on their own rhythm.

## Consequences

A breaking change in 0.7.0. Rule R5 and the cluster comment were corrected in the same pass.
