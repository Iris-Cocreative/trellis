# D37. The name Trellis

## Context

The working name was Iris Foundation, and three names in the code carried it: the layers, the package and the runtime global.

## Options considered

The names weighed: the working name; two names tied to a single product; Trellis; Stave; and Plinth. The working name lost because "Foundation" is another CSS framework's name. The two product names lost because the framework must outlive any one product. Stave was the second choice, strong for the type rule and weaker for the lattice. Plinth was solid but static. "Grid" is cold. Trellis names the lattice, carries the growth the README keeps returning to, and is not another CSS framework's name. The bare package name is taken on npm, so the package is scoped.

Also weighed: a partial rename that kept the old layer names and runtime global, against a complete one. Complete was chosen because nothing consumed the files.

## Decision

Trellis, everywhere: the repository, the cascade layers, the package (`@iris-cocreative/trellis`) and the runtime global (`window.Trellis`). "The foundation" stays as the common noun in a sentence.

## Consequences

Every rename is listed as breaking in 0.8.0, though nothing consumed the files yet.
