# D37. The name Trellis

## Context

The working name was Iris Foundation, and three names in the code carried it: the layers, the package and the runtime global.

## Options considered

"Foundation" is another CSS framework's name. "Grid" is cold. Trellis names the lattice, carries the growth the README keeps returning to, and is not another CSS framework's name. The bare package name is taken on npm, so the package is scoped.

## Decision

Trellis, everywhere: the repository, the cascade layers, the package (`@iris-cocreative/trellis`) and the runtime global (`window.Trellis`). "The foundation" stays as the common noun in a sentence.

## Consequences

Every rename is listed as breaking in 0.8.0, though nothing consumed the files yet.
