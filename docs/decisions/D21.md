# D21. Namespace the cascade layers

## Context

The second app loads Tailwind, whose layers are named `theme`, `base`, `components` and `utilities`. Unnamespaced, the foundation's layers merged with them.

## Options considered

Each import order without a layer statement: `tests/layers.js` shows that neither is safe (a utility margin loses, or preflight flattens the type roles). Namespaced layers with one statement, `@layer theme, base, iris, components, utilities;`: chosen.

## Decision

Every layer sits under one namespace (`iris` then, `trellis` since 0.8.0), and a project beside Tailwind states the order first.

## Consequences

A product layer declares `@layer trellis.product`. `contract.js` fails a layer outside the namespace. Proving it against real Tailwind is a later spike.
