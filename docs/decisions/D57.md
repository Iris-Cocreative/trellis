# D57. The runtime closes a modal on a true backdrop click

## Context

Pressing inside a modal's card (to select text) and letting go outside it closed the modal: a click whose press and release land on different elements goes to their common ancestor, the dialog itself, which the README's one line of dismiss script treated as the backdrop. The native `closedby="any"` doesn't help, because the modal is a full-screen dialog whose padding plays the backdrop.

## Options considered

Weighed at the time, on a decision card in the plan: document a correct snippet for every app to copy; the runtime handles it once, with an opt-out; or a separate small runtime file, which breaks the promise of one script to load.

## Decision

`settle.js` closes a `dialog.modal` only when both the press and the click land on the dialog itself. `data-trellis-stay` opts a modal out (one that must be answered). The snippet stays in the README and `REACT.md` for apps that opt out or do it their own way.

## Consequences

`settle.js` grows beyond settling, and says so. The README's "a backdrop click is the app's one line of script" no longer holds: the runtime does it. `tests/layout.js` presses inside and releases outside, and checks the modal stays open.
