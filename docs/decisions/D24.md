# D24. Prose takes bare tags

## Context

The apps carry rich content from editors and markdown, which arrives as bare tags with no classes. Content management is central to both.

## Options considered

Sanitize when content is saved, or style what arrives. The decision is both: sanitize on save where you can, and this is the floor for where you cannot.

## Decision

One class on the wrapper, `.prose`, maps every tag to its role and settles every block. For what an editor emits with no role: drop type, color, background and space from inline styles and keep weight, style and decoration; drop the same plus margins, padding and float from block styles and keep `text-align`; hide empty paragraphs; flatten class-less nested divs; and give unknown elements a block that rounds to whole cells.

## Consequences

`settle.js` runs in every browser for what CSS cannot round in prose (`--settle-start`, `data-prose-empty`). One case stays unsettled: bare text mixed with blocks inside a pasted div.
