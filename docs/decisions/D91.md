# D91. A slider is a range input, and the runtime says where its thumb is

## Context

Core had no slider. The specimen needed one twice in a week and built it twice: the ratio playground drew a thin track inked up to the thumb, with a variant that inks a stretch between two values, and the Color study drew a thicker track painted with a scale and a thumb filled with the chosen color. The two shared a row height and a thumb size and nothing else, and one variable, `--range-thumb`, meant a size in one and a color in the other.

A range input's filled stretch is the hard part. Firefox has a pseudo-element for it; Chromium and WebKit have none, and CSS cannot read an input's value.

## Options considered

Named while building it; the owner asked for the primitive, not for these:

A slider built from elements, with its own pointer and keyboard handling. It can draw anything, and it gives up what the browser's input does for nothing: the keyboard, the form, the accessibility tree, touch.

A range input with a plain track, no filled stretch. No script, and a slider that does not show its value along its length.

A range input whose filled stretch comes from a variable a script writes. The specimen's playground already did this for itself.

## Decision

`.range` is an `input type="range"`. Its row is two cells tall, its track a quarter cell thick, its thumb a cell and a half across; on a coarse pointer the thumb is two cells and the row is as tall as the touch target, since the whole row takes a drag.

The track is a gradient: the slider's ink up to `--range-at`, its rest after. `settle.js` writes `--range-at`, 0 to 1, when a slider arrives and on every `input`. Setting `.value` from a script fires no event, so that script calls `Trellis.range(el)`. Without the runtime the track is plain and the thumb still moves.

`.cc-zone` inks the stretch from `--range-a` to `--range-b` instead. A slider that draws a scale sets `--range-fill`, and may set `--range-thumb-fill`. Size is `--range-thumb`, always.

## Consequences

- One more thing `settle.js` writes, in every browser, and one more function on `Trellis`.
- A framework that sets `value` from state must set `--range-at` itself or call `Trellis.range(el)`; `REACT.md` says how.
- The specimen's two sliders are gone; both sections use `.range`.
- `tests/layout.js` checks the row, the thumb, `--range-at` after a move and after `Trellis.range()`, a slider added later, and the touch target, in both engines.
