# D29. Four tiers

## Context

Not everything an app needs belongs in the CSS framework.

## Options considered

The owner first framed it as one design system template holding every pattern. The review session proposed tiers, and the owner agreed.

## Decision

Core holds tokens, anatomy, type and primitives. The kit holds patterns built only from them. Engines such as node maps, wires and globes live with their products. Icons and images are assets with rules.

## Consequences

Kit items are filed separately from core. An engine never enters this repository.

## Date

2026-11-10.

## Who

The owner, on the review session's proposal.
