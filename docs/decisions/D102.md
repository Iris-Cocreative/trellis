# D102. An eyebrow's own case

## Context

The label and the eyebrow shared one case and one letter spacing (`--label-case`, `--label-tracking`). The community app's field labels are in sentence case, so it set `--label-case: none`; its section eyebrows ("One schedule") are small spaced capitals, and with the shared knob they turned to sentence case too.

## Decision

`--eyebrow-case` and `--eyebrow-tracking`, unset in core so they follow the label's (on every scope too, D96). A product that sets neither sees no change. The eyebrow's size is unchanged: the label one paragraph step up.

## Consequences

Labels and eyebrows can differ in case and spacing. Their sizes still move together; a product whose eyebrow is the label's size, not a step up, would need a step knob, which waits for a second app to ask (it touches `math.js`).
