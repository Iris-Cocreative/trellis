# D35. Native apps are a hybrid

## Context

The first app has a native mobile app with web views inside it. React Native has no CSS.

## Options considered

Three other options were weighed: web views for everything; a native toolkit with no CSS for everything; fully native per platform. The hybrid won because the first app's mobile app already is one.

## Decision

Web views carry Trellis CSS unchanged. Native screens take the seed as data.

## Consequences

The token source (D43) and the math module (D44) exist so a native screen and a web screen share one seed. Every rule needs a second implementation for native screens.
