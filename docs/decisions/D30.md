# D30. Fully custom projects only

## Context

Some sites are built in a visual builder with its own design system.

## Options considered

The first statement was "all projects moving forward". That would have put a third authority over sites built in a visual builder. The owner narrowed it to fully custom projects. Narrower still, and also set aside: only the two apps.

## Decision

Trellis is the CSS framework for every fully custom project: apps and sites whose markup you write. A site built in a visual builder keeps that builder's design system.

## Consequences

The README states the scope. A surface uses Trellis or another system, not both.

## Date

2026-11-06.

The owner.
