# D2. Products only turn knobs

## Context

Two apps share one core. If a product layer may override anything, the products drift apart again.

## Options considered

Not recorded. The sources say what was chosen, not what else was weighed. Flagged for the owner.

## Decision

A product layer only sets variables on `:root`. Primitives read the knobs; variants and contexts set the primitive's own variables, so a product never overrides a variant by accident.

## Consequences

Rule R14. `tests/contract.js` fails a layer that sets anything else. Two invented example layers prove a product can reshape everything this way.
