# D12. A surface's edge is a plane outside its box

## Context

A border is part of a box's size, so a bordered card would be one line larger than the cells it occupies.

## Options considered

A real border: it changes the box's size. Controls with a fixed height keep this, and give the border back in their padding. An `::after` frame one line larger: chosen for surfaces.

## Decision

A card draws its edge as an `::after` frame one line larger: inside the box on the left and top, just outside on the right and bottom, so each edge lies on its grid line's pixels.

## Consequences

Rule R3. A surface that clips would cut the frame off, so it keeps an inset outline or lets an inner scroller clip.
