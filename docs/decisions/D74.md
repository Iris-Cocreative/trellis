# D74. A surface with a set width is a container

## Context

The definition says a surface is a container, so its type answers to its width. `.float` (popover, options card, tooltip), `.chat-item-bubble` and the prose `pre` painted a ground, an edge, a corner and padding with no `container-type`.

## Options considered

Weighed at the time, on a decision card in the plan: A, the definition gains a clause: a surface that holds no type roles of its own need not be a container; B, they become containers, so type inside a float or a bubble answers to its width.

## Decision

B where the width is set. The options card (16 cells wide) and the prose `pre` (the column's width) become containers (`container-type: inline-size`). A surface that sizes to its content, a tooltip or a chat bubble, need not be one: a container's width can't come from what it holds.

## Consequences

A code change in core: two declarations. The definition gains the clause about surfaces that size to their content.
