# D7. Typed division for the fit

## Context

The fit divides the screen's width by the cell's target to get a count. CSS had no reliable way to divide two lengths.

## Options considered

The `tan(atan2())` trick: WebKit computes it wrongly with viewport units, so the count came out 0 and every iPhone page was blank. Typed division (`100vw / 1rem`) behind `@supports`: chosen.

## Decision

The count uses typed division behind `@supports`, `--cells` is unregistered, and the fitted cell is clamped to 0.8 to 1.25 times its target.

## Consequences

A browser without typed division keeps a whole cell and does not fit. A browser that gets the math wrong still lays out a usable page.
