# D75. Floats and modals draw an outline

## Context

R3 says a surface draws its edge as an `::after` plane one line larger, so each edge lies on its grid line's pixels. `.float` and `.modal-inner` draw theirs as an inset outline instead, which fits R16: they align to an anchor or the screen, not the grid.

## Options considered

Weighed at the time, on a decision card in the plan: A, a stated exception: a surface that doesn't sit on the grid draws an inset outline, and R3's page says so; B, floats and modals draw the `::after` plane too.

## Decision

A. A surface that doesn't sit on the grid, a float or a modal, draws its edge as an inset outline. R3 and A4 state it as an exception.

## Consequences

No code changes.
