# D96. Scopes: a product nested in a product

## Context

A product set its knobs on `:root`, and every role was worked out there. A custom property's `var()` is resolved where it is declared, so a seed set on an inner box reached nothing: the README said so, and told a context to set the role instead, which rule 14 forbids a product. One look per page.

The second app to adopt Trellis, Interbeing (a platform for several communities of practice), has one look per community on the same page: the home holds two communities' archways side by side, each in its own colors and heading font; the schedule colors each event by its community; the Chapel is night on a day page. It had six hand-written token sets switched by an attribute. Agent Weaver, the first app, builds a whole theme from three colors in a script and writes the roles inline on the root: the same idea, for the whole page only.

A study (`experiments/scopes/`) re-ran the derivations on every `[data-product]` element and drew Interbeing's ecosystem, its two communities and the Chapel from Trellis primitives alone. It held in both themes. It also found that every one of Interbeing's spaces has paper of one hue and ink of another (linen with forest ink, night teal with bone), which one neutral seed can't say.

## Options considered

Weighed at the time:

**What a scope inherits.** A seed the outer product chose by hand (its neutral, say), in a scope that sets only its accent: keep the outer choice, or follow the scope's accent? The study re-derived everything. The owner chose to keep the outer choice: a lot is shared across an ecosystem, and a community sets only what makes it itself.

**A new attribute** (`data-scope`) beside `data-product`. A scope is a product: the same knobs, the same file, the same contrast floors. One word is enough.

Named while building it, not weighed at the time:

**Re-running every follower on every scope as a default.** A default declared on a scope resets what an outer layer set, so "choices carry" can't hold that way. A follower has no default instead, and is read with its derivation as the fallback.

**Working the five type values out on each text element**, so any box could set them. It cost WebKit about a fifth of its first settle on 5,000 blocks (`tests/perf.js`: 1,337 to 1,599ms before, 1,593 to 1,926ms after, on the same PC). They are worked out on the root and on every scope instead, and a box that sets the seven, like the specimen's ratio playground, is a scope.

## Decision

`data-product` may sit on any element. A product layer may hold, after its `:root[data-product]` rule, `[data-product="part"]` rules, each setting knobs for its scope.

- **Choices carry, what follows follows again.** A knob a layer set carries into every scope inside it. A knob nobody set follows again from the scope's own values. So the follower knobs have no default: `--seed-neutral`, the five kinds, `--seed-topic` and the three statuses; `--rp-min`, `--rp-max`, `--body-min`, `--h1-min`, `--label-min`; `--font-heading`; `--density-card-pad-inline` and `-block`. Core reads each as `var(--knob, its derivation)`.
- **The roles are worked out on `:root` and on every `[data-product]`.** A scope that sets a seed recolors everything in it. The five type values that follow are worked out there too (`--type-*`), so a box that sets the seven is a scope.
- **Two more seeds: ground and ink.** `--seed-ground` colors every ground and edge, `--seed-ink` every text role. Both follow the neutral unless set.
- **A mood is a scope with `data-theme`.** `light-dark()` answers to the element's own color scheme, so `data-theme="dark"` on a scope makes it night on a day page. Such a scope paints its ground, since its ink would not read on the page's. Every scope sets its text color, its font and the `--surface` its children read.
- **The contract checks each scope.** `tests/contract.js` checks contrast for the root and for each scope, the scope's seeds over the root's, in both themes. `math.js` has `scope()`, which composes them the same way, and `tests/math.js` checks the browser against it.

## Consequences

A community, a section or a mood is a few lines of a product layer. Agent Weaver's themes can become scopes on the root, and drop the script that writes roles.

Breaking: a follower knob read directly (`var(--seed-neutral)`) is empty unless a layer set it. Nothing in core or the known apps read one. `--type-*` are core's own, not knobs.

Not settled: a ground for night that differs in hue from the day's (Interbeing's Common Ground is linen by day and forest by night); a product's own seeds (Interbeing's gold); the other knobs that default to a knob (`--density-seg-pad`, the tag sizes) still resolve on the root.
