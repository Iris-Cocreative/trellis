# D49. The knowledge base first, as an audit

## Context

Nothing consumes Trellis yet, so checking the approach and the decisions is still cheap.

The owner's first intent was the whole knowledge base before any building, as a check on the approach and the decisions. What happened by default was building first. The middle course was chosen: four chapters now, since nothing consumes Trellis yet and the check is still cheap.

## Decision
