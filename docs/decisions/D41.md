# D41. The MIT license

## Context

A public repository needs a license.

## Options considered

Apache 2.0 was the other option named, for its explicit patent grant. MIT was chosen as the usual license for a CSS framework.

Not weighed at the time. Option named since: no license until 1.0.

## Decision

MIT, held by Iris Cocreative.

## Consequences

`contract.js` fails if the license or its line in `package.json` goes missing.
