# The Seed

Two measures, and two ways they meet the world: a cell and a ratio, answering to the screen and to the box they are in. Everything else in Trellis is grown from these. This chapter says what each one is, why it exists, how it is computed, and where it lives in the code.

Above the pages sit the [principles](principles.md): the higher-order ideas, one sentence each, each tied to the rules that keep it.

| ID | Page | In one line |
|---|---|---|
| [S1](S1.md) | The cell | The measure of space. It halves and doubles, and follows the reader's text size up to 1.5 times. |
| [S2](S2.md) | The ratio | The measure of type. Headings step down from H1 by one ratio, paragraphs step out from body by another. |
| [S3](S3.md) | Response | Both measures answer to the screen: whole cells on a wide screen, fitted cells on a touch screen. |
| [S4](S4.md) | Context | Both measures answer to the box they are in: type sizes come from the container, and a context changes variables. |
| [S5](S5.md) | Lines are planes | A line occupies the pixels just after its coordinate, so N cells need N cells plus one line. |
| [S6](S6.md) | Point, line, plane | Every mark is one of three, each sized from the seed. |
| [S7](S7.md) | The masters | The five references the seed draws on, and where each one shows in the code. |
| [S8](S8.md) | Why relationships replace values | The drift that started Trellis, and the answer: values become relationships, relationships become checked rules. |

The README's sections "The seed", "The math, in plain words" and "The token source" are the reference these pages explain.
